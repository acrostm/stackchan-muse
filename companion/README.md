# 豆包 TTS 适配器

`doubao.py` 使用固定的豆包官方 HTTP V3 接口；不接受任意上游地址，不跟随重定向，不重试付费请求。
将逐行 JSON 内的 base64 音频还原为 MP3；只有收到完成事件、音频非空且不超过设备 512 KiB 缓冲时返回。
不记录文本、音频或密钥。异常和不完整响应会失败，不向播放器提供部分音频。

已用本机凭据完成中文短句真实合成，输出 24 kHz 单声道、64 kbps MP3。
这不代表机器人扬声器已验证。首个联调可使用桥接服务，日常是否保留主机依赖仍待决定。

本机试运行：`python3 -m companion.tts_server`，默认仅监听回环地址。
机器人联调时显式传入 Mac 的局域网 IPv4：`--bind <Mac局域网IP>`。
固件配置的 URL 使用 `http://<Mac局域网IP>:8765/tts`，`CONFIG_MUSE_LOCAL_TTS_TOKEN` 使用私有配置中的 `tts_proxy_token`。
仅用于可信局域网，不做公网端口映射。局域网 HTTP 不提供传输加密。

服务目前为单设备、一次一个合成；尚未完成设备端取消和同步 HTTP 阻塞改造，不是已验收的发布服务。
