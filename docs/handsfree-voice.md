# 免手持唤醒、VAD 与续听

状态：策略核心已有可执行 C 测试；尚未接入真实识别模型、录音路径、设置或固件构建。
不能据此宣称设备已经能免手持对话。

`muse_handsfree_core.[ch]` 仅消费唤醒结果与新鲜 VAD 语音样本时长，不读取音频，
不把能量阈值冒充语音分类。尚待接入官方 ESP-SR 模型；必须先通过当前 ESP-IDF
6.0.1 的真实编译/链接、模型分区检查和运行资源测量。

策略默认关闭。开启后先清空旧音频并冷却；模型检测到唤醒后只开始本地缓冲，
未积累至少 300 毫秒有效语音不允许提交。无语音五秒丢弃，短语音后的静默也丢弃，
有效语音后静默 800 毫秒结束，录音上限十五秒。语音时长依据实际 VAD 样本，
不能因 CPU 阻塞或延迟调用而累计更多语音；重复时刻的分类结果不重复计数。

播放/等待期间禁止新唤醒，模型状态与旧 PCM 缓存必须清理。只有实际本地轮次与
播放完成事件能开启续听；HTTP 成功、开始合成或收到文字不算播放完成。
续听在 600 毫秒冷却后最多八秒，超时回到需要唤醒词的待机。
取消、关闭、异常时钟或严重音频间隔使当前代次失效；旧完成事件不能重新打开麦克风。
物理 PTT 仍保留原来的两秒误触保护，不能用自动录音来源绕过物理取消结果。

拟接入官方 ESP-SR 2.6.0。官方清单含 `wn9_histackchan_tts3`（Hi, Stack Chan），
并未把它当作 Muse 唤醒词。最终默认词、检出率和误唤醒需要实际模型与桌面测试。
官方清单允许加载外部模型，但不代表当前项目已有自定义 Muse 模型。
