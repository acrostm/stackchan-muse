# 看向用户：实施与验证

状态：主机控制、OpenCV 检测入口与 USB 设备通道已实现并通过主机测试；无账号相机配置编译通过。真实取帧受 macOS 权限阻止，设备运动和并发验收待完成。

`companion/tracking.py` 接收归一化人脸矩形与同一单调时钟的取帧时间。
它不读取摄像头、不保存图像、不做人脸身份识别，也不直接写舵机。
初次选择最大脸；随后只关联距离上次位置较近的目标，避免突然追随另一张脸。
相机与机器人位置差异通过 yaw/pitch 偏置调整，不能把电脑画面中心直接视为机器人正前方。

控制核心包含画面中心死区、指数平滑、每秒角度上限、单次积分时间上限、
过期/重复/乱序帧拒绝和丢脸超时。短暂丢脸不产生新目标；超时后缓慢回到偏置中心。
停止后必须显式重新启用；没有目标时不扫房。

设备适配现已包含：每设备校准、单一动作仲裁、低于明确用户命令的
tracking 优先级、设备本地 TTL、跟踪会话代次与递增序号、停止后不恢复。
固件弹簧轨迹另有独立硬角速度上限：BSP 速度 0..1000 对应 2..62 度/秒；
跟踪使用速度 200，即轨迹上限 14 度/秒。量化后的实际电机速度仍须测量。
不能用循环 `head.look` 代替该通道，因为显式命令优先级和无到期时间会破坏上述约束。
串口断开、检测阻塞和主机退出时也靠设备端到期机制停止。
新一轮说话只作废旧回复手势，不终止独立开启的跟踪；点脸紧停、拾起、
关机和明确头部命令仍会终止跟踪。该并发策略已通过生产 C 函数测试，音频质量与延迟仍待实机验收。

检测器先采用 OpenCV 的级联人脸检测作为可重复基线；参考
[OpenCV 官方教程](https://docs.opencv.org/4.13.0/db/d28/tutorial_cascade_classifier.html)。
实际依赖已锁定在 `companion/requirements-tracking.txt`；帧率、漏检和背景误检须实测，
不能用控制器的合成矩形测试作为相机或跟踪通过的证据。

现有测试覆盖目标关联、偏置/死区、暂停后限速、丢失后回中、陈旧与乱序帧、
停止锁存和无效输入。待验收：相机权限与取帧、实际脸检测、设备协议、显式命令
抢占、紧停、重连不恢复、音频并发及原计划长时间稳定性。

## 本机运行

使用 Python 3.12 或更新版本（锁定的 NumPy 要求）。在项目根目录执行：

```sh
python3 -m venv .private/tracking-env
.private/tracking-env/bin/python -m pip install -r companion/requirements-tracking.txt
.private/tracking-env/bin/python -m companion.face_tracking --seconds 10
```

默认只输出目标角度，不连接机器人。macOS 须允许运行进程使用摄像头。
模型来自已安装 OpenCV 的本地数据目录；不下载用户照片，不存储帧或做人名识别。
确认设备校准、限位与紧停实机验收后，显式开启：

```sh
.private/tracking-env/bin/python -m companion.face_tracking --move --port /dev/cu.usbmodem1101
```

按 Ctrl-C 退出。摄像头失败、设备拒绝、响应超时或部分写入都让客户端锁存失败，
不会重连后自动恢复。退出只请求停止本会话，不会停止后来接管头部的明确用户命令。

## 设备串口协议 v1

仅走现有物理 USB 控制台，不增加局域网监听端口。

- `>head.track.begin`：在已校准且没有 pet/明确动作时建立新会话；返回 JSON 版本与 generation，0 表示拒绝。
- `>head.track=1,GEN,SEQ,YAW,PITCH,TTL`：角度单位为十分之一度；yaw -600..600，pitch 0..600，TTL 100..1000 毫秒；SEQ 必须严格递增。
- 每个目标返回包含 version、generation、sequence、accepted 和 error 的 JSON；客户端只接受当前请求的确认。
- `>head.track.stop=GEN`：只停止匹配的活跃跟踪会话。旧客户端不能停掉新动作。
- 设备以自身单调时钟检查到期；反馈和 UART 阻塞后、启用扭矩前会重查。超时后旧 generation 永久失效，必须显式重新开启。

实时无脸帧短暂维持最后的受限角度，丢脸超过一秒后平滑回中；停止取帧则不再续租，
设备在最后目标 TTL 后停止并使会话失效。检测器卡住后返回的旧帧不能触发自动重开。

当前证据：73 项项目测试通过；生产 C 跟踪/解析/仲裁函数、USB 客户端与假摄像头
流程均测试。真实 OpenCV 模型加载及空帧检测通过；真实相机、物理角度、丢线停机
延迟、明确命令抢占以及音频并发仍需实机测量。
